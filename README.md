# The Ultimate Syteline v10 API Guide - Working Examples

This repo contains a series progressively complex Syteline API wrapper examples, written in modern .NET, meant to be used in concert with the [Ultimate Syteline v10 API Guide](https://www.linkedin.com/pulse/ultimate-syteline-v10-api-guide-part-1-overview-decision-mercer-4ba3c/) series of articles, published on LinkedIn.

To try it out, clone the repo, enter you credentials for whichever method you want to use (direct or ION), and run the program.

# Examples

## Example 00 (RESTv2)

This example solely handles authentication and shows how to obtain auth tokens directly and through ION. This goes with [Part 2](https://www.linkedin.com/pulse/ultimate-syteline-v10-api-guide-part-2-restv2-setup-andy-mercer-4hpqc/) of the API Guide.

## Example 01 (RESTv2)

This example show how to load/export records. This goes with [Part 3](https://www.linkedin.com/pulse/ultimate-syteline-v10-api-guide-part-3-restv2-loading-andy-mercer-qiykc/) of the API Guide.

## Example 02 (RESTv2)

This example shows how to load/export records in batches, using standard bookmark-based pagination. This goes with [Part 3](https://www.linkedin.com/pulse/ultimate-syteline-v10-api-guide-part-3-restv2-loading-andy-mercer-qiykc/) of the API Guide.

## Example 03 (RESTv2)

This example shows how to load/export records from CLMs in batches, using property-based pagination.  This goes with [Part 4](https://www.linkedin.com/pulse/ultimate-syteline-v10-api-guide-part-4-restv2-loading-andy-mercer-km4yc/) of the API Guide.

## Example 04 (RESTv2)

This example shows how to import/insert records.  This goes with [Part 5](https://www.linkedin.com/pulse/ultimate-syteline-v10-api-guide-part-5-restv2-inserting-andy-mercer-u2mef/) of the API Guide.
